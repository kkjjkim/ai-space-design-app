## 2. 컨셉 — "각을 잡는다"

브랜드각의 '각'은 **각 잡다**(제대로 자리 잡게 하다)다. 사이트 전체의 움직임 언어를 여기서 가져온다.
- 흩어지고 비뚤어진 것 → 한 방향으로 정렬
- 선(도면) → 면(공간) → 빛(운영 중인 가게)

## 3. 대표 효과 3가지 (이 사이트만의 첫인상)

| # | 어디 | 무엇 | 도구 | 왜 |
|---|---|---|---|---|
| 1 | 첫 화면 | **도면이 가게가 되는 3D** — 선으로만 그린 매장(벽·카운터·조명·테이블)이 스크롤하면 재질·빛이 차오르며 실제 공간이 됨. 마우스에 따라 살짝 기울어짐 | three.js (동적 불러오기, 선→면 셰이더 uniform을 ScrollTrigger로) | "사업 계획 → 설계 → 시공"을 한 장면으로. 말보다 빨리 이해됨 |
| 2 | 문제 섹션 | **각 잡기** — 비뚤게 흩어진 "돈 새는 결정" 카드 7장(컨셉 없이 공사, 권리금 과지불, 동선 실수…)이 스크롤에 맞춰 회전이 풀리며 한 줄로 정렬 | GSAP ScrollTrigger (pin + scrub) | 브랜드 이름과 해법이 한 동작으로 연결 |
| 3 | 컨셉 갤러리 | **조각이 모여 한 공간** (Stanzza식) + 컨셉 간 넘어갈 때 번짐 전환(dsgn식) | GSAP + three.js 셰이더 1개(전환용) | 컨셉 10개를 "넘겨보는" 게 아니라 "들어가 보는" 경험 |

보조 효과(대표 효과를 해치지 않는 선에서):
- 큰 문장 글자 차오름(SplitText 대신 자체 split), 섹션 경계는 직선 대신 "각진" 사선 마스크
- 결과물 미리보기는 가로로 흐르는 구역(pin + 가로 스크롤)
- CTA 버튼 자석처럼 끌림, 컨셉 사진 위 마우스 따라오는 따뜻한 빛

지킬 것 (전역 지침 5번):
- 첫 화면 글·이미지는 3D보다 먼저 뜬다. three.js는 `import()` 로 동적 로드, 화면 밖이면 렌더 중지
- `prefers-reduced-motion`·저사양(deviceMemory ≤ 4, 코어 ≤ 4)·모바일 저전력은 정지 이미지 대체
- 390px·1440px 직접 확인. Lighthouse 성능 점수 개편 전보다 떨어지면 안 됨(SEO 유입이 생명줄)

## 4. 설득 구조 다시 짜기

원칙: **실적이 없어도 확인 가능한 것으로 신뢰를 만든다. 지어내지 않는다.**

| 순서 | 섹션 | 방문자 속마음 | 넣을 것 |
|---|---|---|---|
| 1 | 첫 화면 | "여긴 뭐 하는 데?" | 한 줄 약속 + 3D 장면. 버튼 2개: **1분 컨셉 진단**(가볍게) / 무료 상담(바로) |
| 2 | 문제 — 각 잡기 | "내 얘기네" | 돈 새는 결정 7가지 (인사이트 글의 실제 내용에서 뽑음, 각 카드 → 해당 글 링크) |
| 3 | 순서 | "그래서 어떻게?" | 사업 → 브랜드 → 공간 → 시공 → 오픈 후. 3D 장면이 단계마다 바뀜 |
| 4 | **받는 결과물 미리보기** (신규, 핵심) | "상담하면 뭘 받는데?" | 컨셉 진단 리포트·예산 배분표·컨셉 보드·평면 동선도 샘플 이미지(가상 매장으로 제작, "샘플" 표기). 실적 대신 **일의 품질을 보여주는 증거** |
| 5 | 컨셉 갤러리 | "감각은 있나?" | 기존 컨셉 10개, "컨셉 예시" 표기는 작게 한 번만 |
| 6 | 확인 가능한 신뢰 | "믿어도 되나?" | 경영지도사 = 중기부 등록 국가자격(조회 방법 안내), 사업자 정보, 상담 원칙(영업 전화 없음·결정 자유), 공개 글 수. **실제 사례·숫자 자리는 만들어 두고 데이터가 생기면 켬** |
| 7 | **자료 받기** (신규) | "아직 상담까진…" | "카페·식당 창업 예산표 + 오픈 전 체크리스트" — 연락처 남기면 메일로. 정보 탐색형 방문자를 연락처로 바꾸는 장치. 인사이트 글 끝에도 같은 카드 |
| 8 | 질문 | "비용은? 지역은?" | 기존 FAQ + 비용 구조 질문(대표 답변 필요) |
| 9 | 신청 | — | 기존 폼 + "통화 시간 고르기"(선택) |

## 5. 대표님이 정해 주셔야 할 것

1. **보여줄 수 있는 실제 증거가 있나요?** 직접 관여한 시공 사진(얼굴·상호 가림), 익명 컨설팅 사례, 경력 연수 — 하나라도 있으면 6번에 들어갑니다. 없으면 4번(결과물 샘플)으로 대신합니다.
2. **상담 이후 비용 구조** — 컨설팅만/설계까지/시공까지 각각 어떻게 받는지 한 줄씩. FAQ에 "비용은?"이 빠지면 고가 서비스는 신청을 안 합니다.
3. 결과물 샘플·추가 이미지 생성(힉스필드, 펜션 샘플과 같은 방식) 비용 사용 여부 — 예상 15~25 크레딧.
