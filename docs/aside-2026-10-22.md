## 6. Resend 도메인 인증 (30분, 도메인 DNS 권한 필요)
- 브랜드각 Vercel의 `RESEND_API_KEY` 를 발급한 Resend 계정에 로그인 → Domains → `brandgak.com` 추가.
- Resend가 보여주는 DNS 레코드(DKIM TXT, SPF TXT, MX)를 도메인 관리 화면(가비아/Vercel DNS 등)에 그대로 추가 → Resend에서 'Verify'.
- 인증되면 Vercel 환경변수 `LEAD_NOTIFY_FROM` 을 `브랜드각 <notify@brandgak.com>` 형식으로 바꾸고 재배포. (지금은 운영자 알림만 가고 손님에게 보내는 메일은 없다.)
- 10/22 기준 Claude 에 연결된 Resend 계정에는 도메인이 0개였다. 다른 계정이면 그 계정에서 진행.
